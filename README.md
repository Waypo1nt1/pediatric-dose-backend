# Расчёт детской дозы препарата

Первая лабораторная: три страницы на Go с шаблонизатором, данные лежат в коллекции в коде.
Услуга — препарат с дозировкой для взрослого, тема 17, раздел «Медицина».

## Запуск

```
go run ./cmd/pediatric-dose-backend
```

Приложение — http://localhost:8080. Изображения и видео берутся из MinIO, он поднимается через
`docker compose up -d`, консоль — http://localhost:9001.

## Страницы

| Адрес | Страница |
| --- | --- |
| `/drugs` | плитка препаратов, фильтр по дозе для взрослого |
| `/drug-feed/1` | лента, с `?next=true` открывает следующий препарат |
| `/drug-draft` | добавление препарата, поля заполняются, но не сохраняются |

Фильтрация и количество лайков считаются на сервере, JavaScript не используется.
Данные — десять препаратов в `internal/app/repository`.

## Структура

```
cmd/pediatric-dose-backend   точка входа
internal/api                 маршруты
internal/app/repository      коллекция препаратов
internal/app/handler         обработчики страниц
templates                    шаблоны трёх страниц и панели вкладок
resources                    стили и шрифты
```
